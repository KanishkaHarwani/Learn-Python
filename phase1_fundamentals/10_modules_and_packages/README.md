# Modules and Packages  (Day 16)

## Overview

Organizing code across files: modules, packages, the import system, and a tour of frequently used standard library modules.

## Key Concepts

- Modules (.py files) and import statement variants (import, from...import, as)
- Packages: __init__.py, package structure, relative vs absolute imports
- `if __name__ == '__main__':` idiom
- The standard library tour: os, sys, math, random, datetime, itertools, collections
- Circular import problems and how to avoid them

## Gotchas

- Circular imports between modules in the same package
- Relative imports failing when a script is run directly vs as a package module
- Shadowing standard library module names with your own filenames (e.g. random.py)
