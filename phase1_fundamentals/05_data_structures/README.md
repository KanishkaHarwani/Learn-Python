# Data Structures  (Day 7-8)

## Overview

Python's built-in containers — list, tuple, dict, set — their mutability, common methods, slicing, and nested data structures.

## Key Concepts

- list: ordered, mutable, methods (append, extend, sort, slicing)
- tuple: ordered, immutable, use cases (fixed records, dict keys)
- dict: key-value mapping, methods (.get, .items, .keys, .values), dict ordering (3.7+)
- set / frozenset: unique unordered elements, set operations (union, intersection)
- Slicing syntax [start:stop:step] across sequences
- Nested data structures (list of dicts, dict of lists)
- collections module preview: Counter, defaultdict, namedtuple

## Gotchas

- Shallow copy vs deep copy (copy.deepcopy) with nested structures
- Mutating a list while iterating over it
- Dict keys must be hashable — lists can't be keys, tuples can
