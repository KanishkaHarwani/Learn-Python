# Phase 1 - Topic 12 - OOP Basics Exercises

## Exercise 01:
Define a class (e.g. Book) with __init__ and instance methods.

## Exercise 02:
Add a @classmethod alternate constructor and a @staticmethod helper to a class.


## Exercise 03:
Create a base class and two subclasses that override a method, use super().

## Exercise 04:
Implement __str__, __repr__, and __eq__ on a custom class.

## Exercise 05:
Use @property to add validation to an attribute setter (e.g. non-negative price).
