# OOP Basics  (Day 18-20)

## Overview

Object-oriented programming fundamentals: classes, instances, attributes, methods, inheritance, and the core dunder methods that make objects behave naturally in Python.

## Key Concepts

- class definition, __init__ constructor, self, instance vs class attributes
- Instance methods, class methods (@classmethod), static methods (@staticmethod)
- Inheritance, method overriding, super()
- Encapsulation conventions: public, _protected, __name-mangled attributes
- Dunder methods: __str__, __repr__, __eq__, __len__ for natural object behavior
- Properties (@property) for controlled attribute access
- Composition vs inheritance (brief intro)

## Gotchas

- Mutable class attributes shared across all instances unintentionally
- Forgetting `self` as the first parameter of instance methods
- Confusing __str__ (user-facing) with __repr__ (developer/debug-facing)
