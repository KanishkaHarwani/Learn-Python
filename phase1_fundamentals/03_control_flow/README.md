# Control Flow  (Day 3-4)

## Overview

Conditional logic and iteration: if/elif/else, for and while loops, break/continue/else-on-loops, and match-case (structural pattern matching).

## Key Concepts

- if / elif / else chains and comparison/logical operators (and, or, not)
- for loops over iterables; range(); enumerate(); zip()
- while loops and infinite loop patterns with break
- break, continue, and the lesser-known for...else / while...else
- match-case structural pattern matching (Python 3.10+)
- Nested loops and loop performance basics

## Gotchas

- Off-by-one errors with range()
- Infinite loops from forgetting to update the loop condition variable
- for...else executes else only if the loop wasn't broken — easy to forget
